# Living City V2 (rule version 2)

Living City V2 adds a new rule version for **new offline matches only**. Rule version 1 (classic rules) stays unchanged for:
- existing saves;
- online and ranked matches;
- the authoritative backend copy in `competition-functions/runtime/game.html`.

## Task 00 — baseline (main @ 7def3bd, 6 Nov 2026)

### Code entry points (inspected before any change)

`game.html` is hash-pinned. New behaviour is added by wrapping functions in a lib module, the same way the existing features do.

| Area | Where | Current behaviour |
|---|---|---|
| Rules defaults | `setup.rules` (game.html ~3498) | `events:false, speedDie:false, even:true, auction:true, interest:true`. Strategic Events (`events2`) is **undefined → off**. |
| Legacy City Events | `EVENTS`, `advanceTurn` wrapper (~4841) | When `set.events` is on, an event runs every 2 rounds. Off by default. |
| Strategic Events | `EV2_DEFS`, `ev2*` (~7374) | Off by default; opt-in toggle in Custom setup, on in City Spotlight. When on: first event in round 3, then every 3 rounds, one event at a time. `newGame` forces `events:false` when `events2` is on, so the two systems never run together. |
| Market Pulse | `lib/market-pulse.js` | Opt-in, local only. Reuses the Strategic Events slot (needs `events2`). Effects are ±10% rent and 15% cheaper building, plus an optional permit (25% discount cap). |
| Online / ranked | `cfgSetOnline`, `createOnline` | `events2` is deleted from online room settings. Online matches run the classic rules, matching the authoritative backend copy. |
| Card decks | `CHANCE` (Lucky Break, 16 cards), `ESUSU` (City Hall, 16 cards), `drawCard` | A deck is stored as a shuffled list of the 16 card indices. A Bail Pass leaves the deck while a player holds it. |
| Staple card effects (to replace) | `CHANCE` 2, 5, 7, 8, 10, 11, 12, 15 · `ESUSU` 2, 3, 7, 10, 11 | Nearest transit at double rent; advance to the top street; back to Start; go to the Lockup; nearest utility at a dice multiple; every player pays you / you pay every player; repairs per home and per tower; advance to a transit hub. |
| Lockup | `sendToJail`, `jailTurn`, `playTurnInner` | Triggered by three doubles, Police Check (30), or a card. Exits: pay bail 60, use a Bail Pass, or roll doubles; you pay bail after the third miss. Owners in the Lockup still collect rent (`jailRent:false`). |
| Buildings | `canBuild`, `build`, `sell`, `G.houses` = 36, `G.hotels` = 12 | Four houses, then a tower; even building; `o.h` runs 0..5. Rent is `r[o.h]`. A full set doubles the unimproved base rent. |
| Landmarks | `lib/landmarks.js` | Collection cosmetics only (city Bronze/Silver/Gold). **No gameplay effect.** |
| Corners | `SQ` 0, 10, 20, 30 | START (payday 220), City Lockup, Rest Stop (optional jackpot), Police Check → Lockup. |
| AI | `aiWantsBuy`, `aiPostTurn`, `aiJailChoice`, `aiRaise`, trade AI | Values streets by price and set completion; builds on full sets. |
| Saves | `save`, `validateSave`, `decodeSave` | `saveVersion` 1, `G.v` 1. There is **no rule version field**. |

### Compatibility plan

- New matches carry `G.rv = 2` only when the match is offline and Living City rules are on. Every V2 hook checks `lc()`, which is `G.rv === 2 && !G.online`.
- A save without `rv` loads with classic rules. Saves are validated per rule version.
- Online room settings never include `rv`.
- The Skyline Cash wallet, Coins, Shop, StoreKit and Collection purchases are not touched.
